## FAQ

### What is XCutors?

XCutors is a collection of Windows desktop tools for running Lua scripts in Roblox games, including executors and a universal loader.

### Is XCutors free to use?

Yes, XCutors is open-source and free to download and use.

### Which executors are included?

XCutors includes Volt, Synapse Z, Potassium, and Wave, with a universal loader xcutorsLoader.

### Do I need to install each executor separately?

No, the universal loader xcutorsLoader manages all executors, so you only need to run the loader.

### Is it compatible with all Windows versions?

XCutors is designed for Windows 10 and later, but may work on older versions with compatibility mode.

### How do I update XCutors?

Check the GitHub releases for the latest version and download it following the same installation steps.

### Can I add custom scripts?

Yes, you can load any Lua script through the interface or paste it directly.
